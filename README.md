# 将棋定跡研究室 Stage18-1 — 配信専用セット（暫定版）

このセットは、ステージ18-1のオフラインPWAだけを抜き出したものです。アプリの10ファイルは先に提供したStage18-1暫定版とバイト単位で同一です。Streamlit版・リバーシ・戦略ゲーム・モデル・個人の定跡JSON・認証情報は含めていません。

アプリの画面とコードを公開し、定跡データは端末と非公開GitHubに保存する運用です。既存の非公開リポジトリの公開設定を変える必要はありません。

## iPhoneから配信する手順

1. このZIPを「ファイル」で展開します。
2. GitHubのSafari画面で新しいリポジトリを作ります。名前は例えば `shogi-offline`。公開設定はこの新しいリポジトリだけ **Public** にします。README自動追加は不要です。
3. 新しいリポジトリのアップロード用リンク、または **Add file → Upload files** を開きます。
4. ZIPを展開したフォルダ内の **11個のファイル全部** を選択してアップロードし、**Commit changes** で保存します。ZIP自体をアップロードする方式ではありません。外側のフォルダも作らず、`index.html`、`app.js`、READMEなどをリポジトリ直下に並べます。
5. **Settings → Pages** を開きます。**Build and deployment → Source** は **Deploy from a branch** を選びます。
6. **Branch: main**、**フォルダ: /(root)** を選んで **Save** を押します。ブランチ名がmain以外ならアップロード先のブランチを選びます。
7. 配信の完了を待ちます。Pages画面に表示されるサイトURLをSafariで開きます。通常は `https://所有者.github.io/shogi-offline/` です。

この配信方法では、先に提供した `.github/workflows/shogi-offline-pages.yml` は使用しません。隠しフォルダの作成も不要です。既存の非公開リポジトリに追加済みの手動起動専用ワークフローは、この新しい配信用リポジトリでは実行しません。

**公開用には、この配信専用ZIPの中身だけを使ってください。元の盤上研究室全体のZIPを公開用リポジトリへアップロードする必要はありません。**

## iPhoneに準備して使う

1. SafariでサイトURLを開き、共有メニューから **ホーム画面に追加** します。「Webアプリとして開く」があれば有効にします。
2. 追加したアイコンから起動します。**オフライン準備完了** と **端末に保存済み** が表示されるまで待ちます。
3. 既存Streamlit版で書き出した全定跡JSONバックアップ、またはGitHub通常保存のスキーマ3 JSONを「ファイル」に保存しておきます。
4. ホーム画面アプリ内で **保存・設定 → JSON取り込み** を選び、件数を確認して取り込みます。取り込みは端末の全定跡を置き換え、置換前のデータを1世代退避します。
5. **端末の保存保持を要求** を押します。
6. 機内モードにしてWi-Fiも切り、入力・閲覧・再読み込み・終了後の起動を確認します。

普段の編集はホーム画面アプリで行います。Safariとホーム画面アプリの保存領域が異なる場合があります。また、公開URLを変更すると別の保存領域になるため、変更前に端末バックアップを書き出してください。

入力・登録手・コメント・評価値・属性・候補順は端末に自動保存します。確定前のコメント入力も退避します。戻る／進む履歴と現在局面は定跡ごとに保存します。**保存済み表示前にOSが終了した場合の直前書込や、OSによるサイトデータ削除までの保持は保証できません。**

## GitHub保存は元の非公開リポジトリへ

**保存・設定 → GitHub読込・保存** の保存先は、個人の定跡JSONを置く元の非公開リポジトリです。この公開配信用リポジトリを、定跡の保存先には指定しません。

対象の非公開リポジトリだけにContents権限を付けたFine-grained PATをその操作のために入力します。トークンは端末保存・キャッシュ・JSONバックアップに保存せず、操作終了・ダイアログ終了・最小化時に入力欄を消去します。

初回は **GitHubから取り込む**、または端末とGitHubの内容が一致しているうちに **接続・基準を確認** して、基準SHAを設定します。オンライン復帰時の **GitHubへ保存** は手動です。別の更新を検出した場合は上書きを止めます。

先にオフラインで編集し、基準をまだ設定していない場合は、非公開リポジトリ内の未作成の新規JSONパスへ保存できます。既存JSONの内容が違う状態で基準を推測して上書きはしません。

他の人が公開URLを開いても、その人の端末に新しい保存領域が作られるだけです。あなたのiPhone内の定跡は表示されず、非公開GitHubのデータもトークンなしでは読み込めません。個人データは公開リポジトリへアップロードしない運用にします。
